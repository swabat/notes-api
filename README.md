# Notes API

REST API для создания и управления заметками.

## Стек технологий

- Python
- FastAPI
- SQLAlchemy 2.0
- Pydantic 2
- SQLite
- Alembic
- Pytest

## Возможности

- Создание, получение, редактирование и удаление заметок (CRUD).
- Создание и получение категорий.
- Привязка заметок к категориям.
- Фильтрация заметок по категории и статусу архива.
- Поиск по заголовку и содержимому.
- Архивирование и восстановление заметок.
- Пагинация с ограничением параметров.
- Валидация входных данных.
- Автоматические тесты API.

## Запуск проекта

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск миграций:

```bash
alembic upgrade head
```

Запуск сервера:

```bash
uvicorn app.main:app --reload
```

Документация API доступна по адресу:

`http://127.0.0.1:8000/docs`

## Тестирование

```bash
python -m pytest -v
```
